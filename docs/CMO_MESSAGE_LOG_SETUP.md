# How to Enable the Message Log in Command: Modern Operations (CMO)
# Cómo Activar el Message Log en Command: Modern Operations

To allow the Tactical Voice Advisor to narrate combat in real time, CMO must write its event log to disk. This is a built-in, 100% automatic feature of CMO and takes only 10 seconds to configure.

Para que el Asesor Táctico por Voz pueda narrar el combate en tiempo real, CMO debe escribir su registro de eventos en disco. Esta es una función nativa oficial de CMO y se configura en 10 segundos.

---

### Step-by-Step Instructions / Instrucciones Paso a Paso

1. Open **Command: Modern Operations**.  
   *Abre Command: Modern Operations.*

2. In the top menu bar, click on **Game** ➔ **Game Options** (or press `Alt + O`).  
   *En el menú superior, haz clic en **Game** ➔ **Game Options** (o pulsa `Alt + O`).*

3. Go to the **Message Log** tab.  
   *Entra en la pestaña **Message Log**.*

4. In Command: Modern Operations, logging to disk is automatic for all enabled message types. Ensure the checkboxes in the **"Show on Message Log"** column are **CHECKED [X]** for the event categories you want to log and hear:
   - `Air Operations` (Takeoffs, landings, RTB)
   - `New Contact` (Air, Surface, Underwater, Weapon)
   - `Contact change`
   - `Unit Damage` / `Unit Lost`
   - `Weapon Damage` / `Weapon Endgame Calculations`
   - `Scenario Events` / `Special Messages`  
   *(En Command: Modern Operations, el guardado en archivo es 100% automático para todos los tipos de mensaje activos. Asegúrate de marcar con [X] las casillas de la columna **"Show on Message Log"** para las categorías que quieras registrar y escuchar).*

5. *(Tip for Full Immersion)*: Check all boxes in the **"Show on Message Log"** column to hear every tactical event!  
   *(Consejo para Inmersión Total)*: ¡Marca todas las casillas de la columna **"Show on Message Log"** para escuchar todos los eventos tácticos!

6. Click **OK** to save.  
   *Haz clic en **OK** para guardar.*

### 🎙️ How to Customize Voice Alerts / Cómo Personalizar los Avisos

- **For Full Immersion Testing:** Check all message types under the **"Show on Message Log"** column in CMO's Message Log to hear everything (Takeoffs, Contacts, Weapon Hits, BDA, Alarms).
- **For a Quieter / Combat-Only Radio:** Uncheck routine categories (such as non-critical contacts or routine air ops) and leave only Combat / Endgame events checked.
- **The Voice Advisor only reads what CMO writes:** You have 100% control over the verbosity directly from CMO!

- **Para Pruebas Inmersivas Completas:** Marca todas las categorías en la columna **"Show on Message Log"** de CMO para escuchar toda la actividad táctica (Despegues, Contactos, Impactos de armas, BDA, Alarmas).
- **Para una Radio Más Silenciosa / Solo Combate:** Desmarca categorías rutinarias y deja marcados únicamente los eventos de combate crítico.
- **El Asesor solo narra lo que CMO escribe:** ¡Tienes control total del nivel de avisos desde el propio juego!
